# Multi-Agent Software Engineering Assistant Course Index

This folder is a from-scratch rebuild course for the project. Lesson 01 is already expanded as the beginner orientation. Lessons 02-20 define the complete accurate build path in chronological order.

Important rule for using these lessons: do not copy from the existing project. Use the existing project only as a reference. When rebuilding, type each file manually and verify each stage before moving forward.

## Lesson List

1. `Lesson-01.md` - Project overview, learning contract, and VS Code orientation.
2. `Lesson-02.md` - Architecture, system diagrams, and folder structure.
3. `Lesson-03.md` - Development environment setup.
4. `Lesson-04.md` - Git setup and repository hygiene.
5. `Lesson-05.md` - Root project files and documentation foundation.
6. `Lesson-06.md` - Backend foundation: Python package, settings, logging, app startup.
7. `Lesson-07.md` - Database layer: SQLAlchemy models, sessions, Alembic.
8. `Lesson-08.md` - Authentication: password hashing, JWT, auth routes.
9. `Lesson-09.md` - API router, dependencies, middleware, and route conventions.
10. `Lesson-10.md` - Repository ingestion with GitHub API.
11. `Lesson-11.md` - Vector store, embeddings, ChromaDB, semantic search.
12. `Lesson-12.md` - AI service, local fallback, Ollama/OpenAI provider boundary.
13. `Lesson-13.md` - Chat and architecture analysis RAG flows.
14. `Lesson-14.md` - Multi-agent workflow with LangGraph and WebSocket events.
15. `Lesson-15.md` - Machine learning training, metrics, prediction API.
16. `Lesson-16.md` - Exports: PDF reports and ZIP generated projects.
17. `Lesson-17.md` - Frontend foundation: Vite, React, Tailwind, providers, layout.
18. `Lesson-18.md` - Frontend pages and workflows.
19. `Lesson-19.md` - Testing, debugging, and CI.
20. `Lesson-20.md` - Docker deployment, verification, refactoring, and future improvements.

## How To Study

Read one lesson. Perform the actions manually. Verify the expected outcome. Only then continue.

If you are using this as interview preparation, explain each lesson aloud in this order:

1. What problem this stage solves.
2. Which files it creates.
3. Which technologies it introduces.
4. How data flows through the stage.
5. What can go wrong and how to debug it.
